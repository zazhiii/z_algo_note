本目录负责按算法知识点索引题目。条目应尽量包含题号、标题、难度、关键标签和一句话提示；完整模板放在 `../templates`。

## 条目边界

- 题单只记录题目链接、分类、难度与一两句提示。
- 原理、复杂度、通用实现和边界注意事项统一链接到 [`templates`](../templates/README.md)。
- 一道题可以出现在多个分类中，但每处都应标出该分类下的练习重点。
