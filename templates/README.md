## 验证要求

- 至少覆盖空输入或最小规模、一般情况和边界规模。
- 使用哨兵值时，不允许不可达状态直接参与加减运算。
- 比较器必须在相等元素上返回 `0`。
- 模板中的题目链接仅作为验证入口，题单分类放在 `../problem-list`。
