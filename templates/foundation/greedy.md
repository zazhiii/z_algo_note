# 贪心

## 原理

贪心算法每一步选择当前最优方案。使用前应给出交换论证、反证法或单调性证明，确认局部最优能够导向全局最优。

## 常见模型

### 区间扫描与优先队列

- 最大重叠区间数可用差分、端点排序或小根堆求解。
- 若端点相接不算重合，同一坐标应先处理右端点，再处理左端点。
- “最多参加会议”类问题可按开始时间扫描，并从当前可选会议中选择结束最早者。

排序加堆的常见时间复杂度为 $O(n\log n)$，空间复杂度为 $O(n)$。

对于“端点相接不算重合”的最大区间重叠数，旧题单记录了三种等价视角：

1. 差分：将左端点右移后做区间加法，再取最大覆盖次数，离散坐标范围可控时为 $O(n)$。
2. 端点排序：所有端点标记左右类型；同一坐标先处理右端点，扫描当前覆盖数，时间为 $O(n\log n)$。
3. 小根堆：区间按左端点排序，弹出所有不再与当前区间重叠的右端点，堆大小即当前重叠数，时间为 $O(n\log n)$。

对于“最多参加会议”模型，按左端点排序并逐日扫描，将当天已经开始的会议加入按结束时间排序的小根堆；删除已经过期的会议后，选择结束最早者。

### 整数拆分

固定拆成 $k$ 份且要求乘积最大时，各份应尽量接近。以下是从旧题单迁移的递归示例，尚未处理大数与取模，不应直接作为竞赛模板复制：

```java
static long splitProduct(long n, int k) {
    if (k == 1) {
        return n;
    }
    long part = n / k;
    return splitProduct(n - part, k - 1) * part;
}
```

旧题单中的原始实现如下。它使用 `int`，与原笔记中的 $n,k\le 10^{12}$ 条件不匹配，仅为保留迁移上下文：

```java
public static int check2(int n, int k) {
    if (k == 1) return n;
    return check2(n - n / k, k - 1) * (n / k);
}
```

### 前后缀边界

“最短无序连续子数组”可以在从左到右扫描时维护前缀最大值，找到最右侧违反单调性的点；再从右到左维护后缀最小值，找到最左侧违反单调性的点。两侧均未出现违规时，数组已经有序。

## 注意事项

- 先验证贪心选择的正确性，不能只凭样例归纳。
- 比较器相等时必须返回 `0`，并警惕减法比较导致溢出。
- 区间问题要明确闭区间、开区间以及相接是否算重叠。
- 乘积可能溢出 `long`；根据题意使用取模或 `BigInteger`。
