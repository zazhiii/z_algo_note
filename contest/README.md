## 维护约定

- 合集按比赛编号组织为二级标题，题目使用三级标题。
- 超长合集后续按年份或连续编号区间拆分，并在本页保留稳定入口。
- `待补`、`exc` 条目应在补题后补充状态和核心知识点。
