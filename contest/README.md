# 比赛记录

本目录保存按平台整理的比赛复盘。题目首次出现时可以保留完整题意、思路和代码；稳定算法实现应进一步整理到 `templates`，题目标签应同步到 `problem-list`。

## 平台索引

- [AtCoder](atcoder/README.md)
- [Codeforces](codeforces/README.md)
- [LeetCode](leetcode/README.md)
- [牛客](nowcoder/README.md)
- [洛谷](luogu/README.md)

## 维护约定

- 每场比赛使用一个文件，比赛名为一级标题，题目使用二级或三级标题。
- 平台目录的 `README.md` 是稳定入口，新比赛按编号加入索引。
- `待补`、`exc` 条目应在补题后补充状态和核心知识点。
