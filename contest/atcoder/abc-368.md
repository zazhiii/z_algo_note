# [ABC 368](https://atcoder.jp/contests/abc368)

[C - Triple Attack](https://atcoder.jp/contests/abc368/tasks/abc368_c)

> 数学

```java
    static public void solve() throws IOException{
        int n = rd.nextInt();
        long ans = 0;
        for(int i = 1; i <= n; i ++){
            int x = rd.nextInt();
            ans += 1L * x / 5 * 3;
            x %= 5;
            while(x > 0){
                ans ++;
                x -= ans % 3 == 0 ? 3 : 1;
            }
        }
        pw.println(ans);
    }
```
