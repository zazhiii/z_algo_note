### 核心思路

预处理每个骰子的每个数出现几次，$cnt[i][x]$ 表示第 $i$ 个骰子中 $x$ 出现几次。枚举每对骰子，再枚举其中一个骰子 $i$ 的每一个数 $x$；若另一个骰子 $j$ 中包含 $x$，则相同数的概率贡献为：

$$
\frac{cnt[i][x]}{k_i}\times\frac{cnt[j][x]}{k_j}
$$

累加每个数的概率，得到这对骰子掷出相同数的概率。

        Map<Integer, Integer>[] map = new Map[n];
        Arrays.setAll(map, i -> new HashMap<>());
        int[] k = new int[n];
        int[] mxa = new int[n];
        double ans = 0;
        for(int i = 0; i < n; i ++){
            k[i] = rd.nextInt();
            for(int j = 0; j < k[i]; j ++){
                int x = rd.nextInt();
                map[i].put(x, map[i].getOrDefault(x, 0) + 1);
                mxa[i] = Math.max(mxa[i], x);
            }
            for(int j = 0; j < i; j ++){
                double res = 0;
                for(int x : map[i].keySet()){
                    if(map[j].containsKey(x)){
                        res += (1d * map[i].get(x) * map[j].get(x)) / (1d * k[i] * k[j]);
                    }
                }
                ans = Math.max(ans, res);
            }
        }
        pw.printf("%.15f", ans);
